A tale of nefarious usage: IPv6 based Covert Channels

Covert channels are communication channels instantiated over legitimate network traffic, providing a reliable, efficient, and stealthy way to exchange data. The rapid adoption of IPv6, led by large Internet Service Providers, and technology companies, together with improvements will bring new security risks to be covered and addressed. In this work, I would like to present and evaluate IPv6 Covert Channels and how they can be efficiently implemented and used for exfiltrate data from on-premises, hybrid and commercial cloud environments such as AWS, Azure and Vultr using an IPv6 network stack.

The presentation shows how easy it is to implement IPv6 covert channels using Python and Scapy, and how to use them to exfiltrate data via a compromised host exploiting a legit communication.
